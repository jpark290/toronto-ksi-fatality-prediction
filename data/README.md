# Data snapshot

`KSI.csv` is the public Toronto KSI dataset snapshot used for the submitted academic project.

Source: [City of Toronto Open Data](https://open.toronto.ca/dataset/motor-vehicle-collisions-involving-killed-or-seriously-injured-persons/)

Licence: [Open Government Licence, Toronto](https://open.toronto.ca/open-data-licence/)

The project snapshot covers the fields and time range available when the team completed the analysis. The live source may change after publication.
